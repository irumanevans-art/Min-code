# 更新日志

每次发版在最小位加 1（`1.0.x`），除非这次改动明确说要升次版本。

## 1.1.3 — 2026-09-14

- 无头会话终于会自己拟名：`-p stream-json` 不会自动写 `ai-title`，首轮成功后主动调 CLI 的 `generate_session_title`（persist），列表不再一直停在第一条用户消息。
- 相册发图跟系统 Photo Picker 上限走，不再人为卡 4 张。
- 搜索只留在会话记录抽屉，并能按正文命中；进行页顶栏放大镜去掉。
- 切模型 / 思考强度时，设置面板顶部立刻转圈并写「正在应用…」，不再只是选项变灰。
- 界面语言：跟随系统，或在设置里强制中文 / English（`values` 英文默认，`values-zh` 中文）。

## 1.1.2 — 2026-09-13

- 会话列表终于能用上 CLI 自动拟的标题：以前只认 transcript 里的 `custom-title`（人手 `/rename`），自动拟名实际写的是 `ai-title`。现在两者都认，人手改名仍优先；回合结束后会再扫一次磁盘，等异步落盘。

## 1.1.1 — 2026-09-13

- 对照 Claude Code CLI 2.1.270：回合结束展示被权限规则拦截的工具（`permission_denials`）；Bash 改文件时展开工具卡能看 diff（`bashEditDiff`）；CLI 配置里可设思考强度上限 `maxEffortLevel`。
- 会话能搜了：抽屉按标题 / 分类 / id 过滤；打开的会话顶栏放大镜搜正文，上/下跳到命中并自动展开折叠的工作块。
- 建议把 Rootfs 里的 CLI 升到 2.1.270（中转站每轮 HTTP 400、headless 误报「等待中」、resume 热切模型丢回复等修在 CLI 侧）。

## 1.1.0 — 2026-09-13

- 更新 Claude Code 时，原生二进制跟着 wrapper 换版本：它是拷到 `bin/claude.exe` 再删掉平台包目录的，不是硬链接。以前文件够大就跳过，界面显示新版本、会话仍跑旧 native。
- 空框顺延改成会话真的打开之后才消耗。判定本身不再清指针，并发满了空框还能用。
- 文件页装 / 重装 Linux 环境和向导一样：官方源连不上换阿里云镜像；手填的地址仍只用这一份。
- `relaunchWith` 用来决定 `--resume` 还是 `--session-id` 的「磁盘上有没有 transcript」补了单测。

## 1.0.12 — 2026-09-12

- 结束会话、切模型、改权限 / 思考强度 / 工作目录等会等 CLI 的操作，一点就进入忙碌态：停止键转圈，副标题写「正在结束会话…」或「正在应用会话设置…」，设置面板里的选项暂时点不动，避免连点。
- 安全分类器或配额把模型降级后，界面上的模型跟着切到实际在跑的那个（只改本会话，不改新会话默认）；聊天流里的说明还在，也可以再手动切回去。
- 会话列表标题改成立刻用 CLI 自拟的名字（`custom-title`），不必等这一轮跑完、transcript 落盘；人手改过的名字仍然优先。
- 关于页的更新日志按版本号折叠，只有最新一条默认展开。
- 深色模式会话轨上的白沫改成沿蓝线弧长走的多粒短痕，拐进螺旋也不再冲出线条；直线段也看得出粒在连续往前。

## 1.0.11 — 2026-09-11

- 停止键现在等价于电脑上的 **Esc**，按官方终端的三档行为分派：
  本轮已经有输出就打断；请求刚发出、一个字都还没吐就**撤回**（对话流里摘掉那条消息，
  原文退回输入框）；有排队中的新消息就打断当前轮、立刻开跑那一条。
  为此追加消息改成由 App 自己排队（以前一发就进 CLI 的内部队列，再也拿不回来）；
  排队中的消息在对话流里标「排队中 · 按停止可撤回」。
- 输入坞下面那条状态行整条撤掉了。模型摘要、上下文、花费是「想起来才看一眼」的参考信息，
  却常驻占着手机上最金贵的一条横向空间，还逼着三样东西互相挤——「今日 … · 本次 …」两个金额
  都在时，用量能吃掉整行，停止键被量成 0 宽**直接从界面上消失**（这就是 sonnet 下按不到停止的原因）。
  现在它们收进输入框左边的「+」：上下文与花费一栏（一圈**潮环** + `880k/1M` + 两笔金额），
  会话设置一栏（点开就是原来的设置面板）。胶囊外面不再有任何一行。
- 停止键搬进胶囊里，紧挨着发送键。它没跟着收进「+」——埋进下拉菜单就要点两次，
  而「停下」必须一按就到。和发送分两个键而不是合成一个：生成中本来就可以追加消息。
- 上下文用量从一道 40 dp 的线改成**潮环**：十二点起手顺时针漫一圈，浪头一粒白沫，
  逼近上限整圈转朱砂。比例这种量画成圆比画成线更直接，也省地方。
- 会话页右上角加了**终端**：和会话同一个 rootfs、同一个 `/workspace` 的真 bash，
  盖在对话上升起，返回键落下。每个在跑的会话预开一个页签、落在它自己的工作目录里。
  （它是平行的 shell，不是会话进程的控制终端——会话跑的是无头 stream-json，没有 TTY。）
- CLI 进程写到 stderr 的每一行现在都能看到了，折叠成对话流里的「进程输出 · N 行」。
  以前只有「像错误」的行会显示，其余当噪声丢掉，真东西混在里面就再也查不到。
  红字的判定没变：可见不等于报警。
- 首界面 Min 的 i 上那颗太极去掉，退回字体自带的点——那枚记号压在流动的海上是唯一不动的东西。
  桌面图标和启动页的太极保留。
