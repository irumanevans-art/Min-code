# 更新日志

每次发版在最小位加 1（`1.0.x`），除非这次改动明确说要升次版本。

## 1.1.12 — 2026-09-17

- **退回输入框的消息再也不会半路丢掉**：启动失败、握手超时、切换失败、会话已关闭时，排队消息会退回输入框；但以前碰上输入框没在屏幕上（切了后台 / 页面没开着），退回的文字会悄悄蒸发，对话流里还留着「已退回」的提示。现在没人接就写进草稿盘，下次打开这个会话时原样躺在输入框里。启动中按停止也一样：排队的消息先退回再停，不再留永远「排队中」的幽灵条目。
- **崩溃横幅不再误报**：被后台协程接住、App 实际没崩的异常，以前和真崩溃写同一个文件 —— 启动时竖起「上次运行崩溃过」的假横幅不说，还可能盖掉你没来得及看的真崩溃堆栈。现在两类记录分开存，横幅只认真崩溃，关于页里两份记录都能看到、都能复制。
- 修复撤销快照的目录消毒漏洞：工具 id 是 `.` 或 `..` 时消毒结果原样放行，快照会落到 checkpoints 根目录并且互相覆盖，撤销可能还原错文件；现在纯点 id 换成等长下划线。

## 1.1.11 — 2026-09-17

- 适配 Claude Code CLI 2.1.274：它从这版起不再为还在连接的 MCP 服务器等那两秒，被工具搜索延迟加载的工具要到后面某一轮才报上来。会话流里那条「会话已建立 · N 个工具」以前发出去就定死在首轮那个偏小的数字上，和顶栏对不上；现在数字长出来会就地改准。没配 MCP 的话本来就碰不到。

## 1.1.10 — 2026-09-17

- **API key 可以存多条**：设置 → 连接现在是一张表，每条是「备注名 + token + 中转地址」。点一下换当前生效的那条，右边那颗笔改内容。token 和地址绑在一起存 —— 换中转站本来就要同时换两样，分开存的结果一定是某次只换了一半。列表上 token 只露头尾。老版本的单个 token 会自动迁成第一条，不用重填。
- **长按会话里的字终于能好好选中**：刚在输入框打过字的时候，长按模型的回答会选不中，或者弹出来的菜单只剩一个按了没反应的「全选」、没有「复制」；切去别的界面再回来又好了。原因是键盘收起时那次"顺手清掉焦点"把选中刚拿到的焦点一起清了。现在只有焦点确实还在输入框上才清。
- **修复生成中的正文停在第一截不动**：Markdown 短文本解析出来的结果被丢掉了，同一条消息后续到达的文字不会重绘。
- **设置里的语言终于能换**：以前点「English」格子会变蓝、值也存下来了，界面却纹丝不动 —— 调的那个方法要求界面用 AppCompat 那一套，而 Min 是纯 Compose，于是它被调用时静默什么也没干。现在 Android 13+ 直接交给系统（顺带把「系统设置 → 应用 → Min → 语言」那个入口也点亮了），更低版本自己接管。改完立刻生效，不用重启。从系统那边改的语言也会同步回设置页。
- **预览槽不再乱弹端口**：工具输出里找「listening on … port N」这类提示的规则收紧了三处。一段 curl 回来的 CSS（`--wp-bound-block-color` … `max-width:100%`）曾被读成端口 100，预览槽弹出一个连不上的 `127.0.0.1:100`。
- 输入框上方那行标签不再换行压字：窄屏 + 放大字体时 `ANTHROPIC_AUTH_TOKEN` 会断成两行，第二行压进上一格的输入框里。

## 1.1.9 — 2026-09-16

- **打的字不再凭空消失**：会话启动失败、握手超时、切换思考强度 / 提示缓存失败时，还排队的消息原样退回输入框，改改就能再发；会话已经关掉时按发送也一样退回，不再留一条永远「排队中」的幽灵消息。
- **CLI 更新失败能自愈**：上次更新中途断掉会留下「外壳已是新版、原生程序还是旧版」的错配，而旧文件看着完好，再点更新永远被判成「已是最新」、旧版就一直跑下去。现在失败会留一个标记，下次更新强制重装原生程序。
- **修复工作区搜索越界**：工作区里放一个指向区外（比如 App 私有目录）的符号链接，搜索会把外面的文件内容读进结果；现在越界的命中直接丢弃。
- 后台 / 长驻命令进进程表失败时给出可见的报错、工具卡标成错误，不再静默跳过；已经进表的工具卡也不会被随后那条拒绝结果翻回错误态。
- 后台协程出错不再把整个 App 带崩：异常落进崩溃记录，关于页照样能看到。
- 修复关闭会话时 CLI 进程可能残留：停止流程必须走完才回收，不再被中途取消。

## 1.1.8 — 2026-09-16

- **追加的话，跑完这一步就听见**：生成中发出的消息不再攥到整轮结束才写出去，而是立刻交给 CLI，由它在下一个循环边界插进这一轮 —— 和终端里的手感对齐。实测（`tools/probe_queue.py`，CLI 2.1.272）：第一个工具刚回结果，模型下一句就在回应你追加的那条，整轮只有一个 `result`。停止键的三档语义没变：排队时按停止仍是「打断当前轮、排队那条接着跑」，只是那条现在由我们留的副本重发（interrupt 帧带 `cancel_queued`，CLI 侧队列会被清空）。
- 会话还没起来时打的字不再凭空消失：先攥着，握手把工作目录切好之后再发。换思考强度 / 缓存 TTL 要重启进程时，排队的消息跟着搬到新进程。
- stdin 改成单消费者串行写。以前两次 `launch` 落在不同线程上抢同一把锁，紧挨着发的两条消息在 CLI 那边的先后没有保证 —— 追加消息立刻出手之后，顺序必须真的算数。
- **工作区文件长按多选**：长按任意一行进入多选，单项菜单挪到行尾的 ⋮（一个不少）。选中后底栏换成导出 / 移动 / 分享 / 删除，顶栏是「已选 N 项」+ 全选 / 反选。多选时锁住横划，免得一个手势把选择栏晾在「环境」页上。
- **批量与整目录导入导出**。导出时问一句：**打包成一个 .zip**（连目录结构，空文件夹也留着），或者**复制到你选的文件夹**（逐个写出去，对方拿到的是散文件；SAF 写不了修改时间，这一点保不住）。导入同样两条路：系统目录选择器整棵拷进来，或者选一个 .zip 解到当前目录 —— 顶层散着两个以上名字时默认帮你套一个文件夹。文件夹终于能导出和分享了（以前 `exportFile` 只认单个文件，菜单里直接灰着）。
- 打包会跳过符号链接（rootfs 里有自指的链接，跟进去就不会停）、`.l2s.*` 和 proc/sys/dev/run；解压侧按实际写出的字节算上限并拒绝所有能跳出目标目录的条目名。**因此 rootfs 归档不是可还原镜像**，只能当文件级备份看。
- **打开方式**：文本、图片、其他应用三选一，可以勾「以后 .md 都这样打开」；记住的偏好在文件太大打不开编辑器时会自动退回默认路由，不会把人送进一个必然报错的界面。
- 往 `linux/` 区导入的入口收起来了 —— 那是系统盘，写进去太容易把环境弄坏；导出和打开方式仍然给。
- 分享用的缓存目录每次写之前先清空。以前分享一次 400 MB 的东西就永久占掉 400 MB。

## 1.1.7 — 2026-09-15

- **预览是「位」**：会话顶栏常驻预览键（终端左侧）。有本机 loopback 才有效；关掉是藏，不是拆。Agent 填 URL 可自动展开一次；进程表「打开」= 按这个键，不再第二套 WebView。
- **进表认后台意图**：主路径是 Bash `run_in_background`；dev-server 白名单只是薄启发式。`can_use_tool` 时后台/长驻 Bash **排他**进进程表并 deny CLI 再跑一遍，消端口双开。
- **身份卡**：后台用 flag、缺命令 `apt-get install -y` 真装、本地页走预览位；去掉「bare & dies」交通规则。会话 / 托管 env 带 `DEBIAN_FRONTEND=noninteractive`。
- **顺一点**：启动后台预解码海纹理 + BitmapShader 预热；会话流式时关掉列表 `animateItem`；进程日志 StateFlow 400ms 节流；代码高亮结果缓存；Baseline Profile（`profileinstaller` + `:baselineprofile` 采集）让首次交互走 AOT。
- 建议 Rootfs CLI ≥ **2.1.271**（MCP-only `-p` resume、headless 等修在 CLI 侧；stream-json 形状无大改）。

## 1.0.11 — 2026-09-11

- 停止键现在等价于电脑上的 **Esc**，按官方终端的三档行为分派：
  本轮已经有输出就打断；请求刚发出、一个字都还没吐就**撤回**（对话流里摘掉那条消息，
  原文退回输入框）；有排队中的新消息就打断当前轮、立刻开跑那一条。
  为此追加消息改成由 App 自己排队（以前一发就进 CLI 的内部队列，再也拿不回来）；
  排队中的消息在对话流里标「排队中 · 按停止可撤回」。
- 输入坞下面那条状态行整条撤掉了。模型摘要、上下文、花费是「想起来才看一眼」的参考信息，
  却常驻占着手机上最金贵的一条横向空间，还逼着三样东西互相挤——「今日 … · 本次 …」两个金额
  都在时，用量能吃掉整行，停止键被量成 0 宽**直接从界面上消失**（这就是 sonnet 下按不到停止的原因）。
  现在它们收进输入框左边的「+」：上下文与花费一栏（一圈**潮环** + `880k/1M` + 两笔金额），
  会话设置一栏（点开就是原来的设置面板）。胶囊外面不再有任何一行。
- 停止键搬进胶囊里，紧挨着发送键。它没跟着收进「+」——埋进下拉菜单就要点两次，
  而「停下」必须一按就到。和发送分两个键而不是合成一个：生成中本来就可以追加消息。
- 上下文用量从一道 40 dp 的线改成**潮环**：十二点起手顺时针漫一圈，浪头一粒白沫，
  逼近上限整圈转朱砂。比例这种量画成圆比画成线更直接，也省地方。
- 会话页右上角加了**终端**：和会话同一个 rootfs、同一个 `/workspace` 的真 bash，
  盖在对话上升起，返回键落下。每个在跑的会话预开一个页签、落在它自己的工作目录里。
  （它是平行的 shell，不是会话进程的控制终端——会话跑的是无头 stream-json，没有 TTY。）
- CLI 进程写到 stderr 的每一行现在都能看到了，折叠成对话流里的「进程输出 · N 行」。
  以前只有「像错误」的行会显示，其余当噪声丢掉，真东西混在里面就再也查不到。
  红字的判定没变：可见不等于报警。
- 首界面 Min 的 i 上那颗太极去掉，退回字体自带的点——那枚记号压在流动的海上是唯一不动的东西。
  桌面图标和启动页的太极保留。
