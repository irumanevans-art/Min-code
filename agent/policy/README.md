## 模型看到什么
拒绝调用时返回模型可理解的理由，需审批时持久记录请求。
## token 代价
规则判断本身不耗 token；auto 审查模型尚未接入。
## 缓存影响
不改系统前缀；审批和结果以追加事件表达。
## 已知限制
当前 PolicyEngine 按模式、readOnly、路径 / 命令判断；Device 写始终 Ask。规则求值、命令解析与完整安全层未实现。
