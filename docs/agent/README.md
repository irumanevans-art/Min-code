# Min Agent · 自研 agent 内核设计

Min 现在在 proot 里跑官方 Claude Code / Codex CLI，从它们的输出流里猜状态。Min Agent 是长在 Min 里的内核：
纯 Kotlin/JVM，随 App 启动即用；文件工作在宿主侧做，只有 shell 进 proot；会话以事件日志为唯一事实来源，
进程随时被杀都能续跑；国产模型是一等公民。Claude Code 的内核能力全部对标。

> 状态：**M0 完成，M1 桌面收口**（2026-09-30）：两种协议、目录 CLI、恢复边界与撕裂验证已落地；20 题评测与真模型 / 缓存对照仍待验收。02 / 04 是完整设计，当前契约以 03 和代码为准，状态见 08。

## 关键决定一览

| # | 决定 | 理由（详见） |
|---|---|---|
| 1 | 三引擎并存：Min Agent 为主；官方 CLI 冻结维护（Claude 订阅唯一路）；Codex 保留 | 条款禁止第三方 harness 用订阅凭证（01） |
| 2 | Kotlin/JVM 纯内核，App 进程内，接口可跨进程 | 00 §3 |
| 3 | 事件日志是唯一事实来源；工具持久化状态机；被杀后任意点恢复 | 七家收敛（00 §2） |
| 4 | 宿主做重活（读写、搜索、diff、快照、网络），proot 只跑 shell / hooks / stdio MCP | 02 §1 |
| 5 | 四套线协议原生 + 数据化怪癖表 + 发送时投影；Anthropic 协议为主干 | 04 §4.2 |
| 6 | 内部协议 MAP（thread/turn/item + seq + 快照），外形对齐 ACP，M6 对外暴露 | 02 §6 |
| 7 | 兼容 Claude Code 配置生态（`.claude/`、CLAUDE.md、AGENTS.md、hooks、skills、plugins、`.mcp.json`） | 用户零迁移（04 §4.7） |
| 8 | 第三方可执行物一律进程外；不做动态插件框架 | 00 §3 |
| 9 | 安全：一套命令解析器、不可绕过的安全底线、路径分级；自建隔离层（seccomp 硬禁网 + proot 写白名单 + 快照回滚），逐层如实标注强度 | 04 §4.4、§4.4.1 |
| 10 | 提示缓存头号指标；任何提示改动必须过请求快照测试与评测 | 07 |
