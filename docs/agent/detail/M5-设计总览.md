## 二、各块定方向

### 1. 插件加载器与市场
- **做法**：照 `plugin-compat` 的 46 个样本（已在 m0，全部待修）实现。加载器吃「合并后的 enabledPlugins + 用户层 / 托管层配置」，吐 `LoadedPlugin`（契约草案在 `PluginLoaderContract.kt`，测试源里）。
- **市场**：支持 git / url / archive 三种源（05 原文）；**不默认启用第三方市场**。
- **待定 1**：要不要让用户从 App 里装第三方插件？装了就等于装了可执行代码（hooks 与 MCP 服务器能跑命令）。我的建议：先只支持从本地目录装，市场只做「看」与「装官方源」，第三方源要用户手动加并明确警告。这是安全决定，需要你点头。

### 2. agent 团队与邮箱
- **做法**：团队 = 一组共享任务清单的子 agent。每个成员一个会话（复用现有 Hub 的子会话），消息走**邮箱**（日志里的事件，不是内存队列），任务清单是一份从日志折叠出来的状态。
- **边界**：成员数上限照 `HubLimits`（手机默认）；成员之间不能绕过权限（审批仍在根会话的树里答）。
- **待定 2**：手机上同时跑多个团队成员的耗电与发热。我的建议：默认最多 3 个并发成员，超了排队；上限做成设置项。

### 3. 定时调度（Cron / /loop / ScheduleWakeup）
- **做法**：Android 上用 `AlarmManager`（精确闹钟需要权限，改用不精确的 + 前台服务里的心跳兜底）。调度到点后拉起一个会话跑一次预设的提示词，结果落日志、通知用户。
- **约束**：App 被系统杀掉时定时任务不跑，这是手机的现实，要写清楚，不能假装可靠。
- **待定 3**：是否允许后台无人值守地跑模型请求？这会花钱（用户的 API 额度）。我的建议：默认关；开了之后每次运行都要有用量上限（复用 `--max-budget-usd` 的思路）。

### 4. auto 模式与审查模型
- **做法**：auto 模式下，每个待审批的工具调用先交给一个审查模型（可配便宜模型，照 CC 的 `autoMode` 配置：environment / hard_deny / soft_deny / allow）判断放行、拒绝或转给人。
- **待定 4（钱）**：审查模型每次调用都要花钱，而且是在每个工具调用前。要不要默认用 Haiku 5.5 作审查？这是花用户额度的决定，我不替你定，**需要你点头**。
- **安全**：审查模型的输入不能包含凭证文件内容（和 MCP OAuth 那批修复同一条纪律）。

### 5. 沙箱与隔离层（Seatbelt / bwrap）
- **做法**：分两层，照 `docs/agent/` 里的设计 04 §117–118 已有的表：
  - proot 白名单（防误操作级，Android 上已有 proot，加可写路径白名单）；
  - seccomp 禁网与危险调用（硬隔离，Linux / Android 可用）；
  - 宿主侧网络代理按域名放行（逐域名在界面上批准）。
- **边界**：Windows 桌面没有 seccomp，桌面只能做到「防误操作」。文档里要写清。
- **待定 5**：网络代理的逐域名批准要在 App 里做一个新界面，是否接受这个 UI 成本？

### 6. Workflow（QuickJS）与 dynamic workflows
- **做法**：脚本在内嵌的 QuickJS 里跑，`agent()` / `parallel()` / `pipeline()` / `phase()` 四个原语（设计 04 第 189 行已有）。节点日志回放用于恢复。
- **风险**：引入 QuickJS 是新依赖，要单独评估 APK 体积与许可证。**待定 6**：是否接受引入 QuickJS？

### 7. Monitor 与后台任务喂回
- **依赖**：先要把后台命令登记进内核（检查点与 rewind 设计 165 行已记为待办）。登记之后，Monitor 按行把输出喂回模型。

### 8. 其余小项
- **ReportFindings / EndConversation / SubagentHandback**：内核小改动，跟随团队与审查做。
- **LSP（proot 内语言服务器，按需装）**：重，放最后。
- **EnterWorktree / ExitWorktree**：已完成（`8f66785a`），从清单上打勾。
- **SendFeedback**：改成「导出诊断包」（本机，用户自己决定发不发）。
- **Artifact**：生成的 HTML 在预览槽打开 / 分享。
