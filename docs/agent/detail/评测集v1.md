# 评测集 v1（50 题）

M3 的验收门槛之一（06-路线图「M3 · 生态与兼容」：评测集 v1（50 题））。在 M1 的 20 题
（`agent/cli/scripts/evaluate.py`，做法见 CODEX_REPORT_2026-09-30 §279 与 08-进度 §7）之上扩到
50 题：题目数据拆到 `agent/cli/scripts/eval_cases.py`，runner 与判分器仍在 `evaluate.py`。

六种题型出 6 题）：

## 判分纪律（沿用 M1）

- **只看事实**：文件字节、退出码、测试文件未改（`unchanged:`/`frozen:`）、会话日志 `events.jsonl`
  里的工具调用与结果（`tool_planned` / `tool_outcome` / `hooks_ran` / `subagent_spawned` /
  `mcp_servers_loaded` / `task_created` / `approval_requested`…）、CLI `--json` 的 `structured_output`
  与 `subtype`。不信模型自己宣称「通过了」。
- **判分器先离线验证**（`check_grader_v1.py`）：每题至少一条「故意做错」的变异——对工作区 / 会话日志
  / 结果行的**副本**做定向破坏，断言对应检查变红、整题判失败；原始产物判绿且永不被改。
  v1 共 53 条变异（22 与 38、46 各两条），全部命中。
- **先模拟后真模型**：`mock_model.py`（anthropic 线 SSE 脚本桩，`/control/scripts` 按题灌脚本）+
  `mock_scripts.py`（50 题的脚本）先把全量跑绿；MCP 用 `eval_mcp_stub.py`（行分隔 JSON-RPC stdio 桩）。
  真模型只完整跑一次；判分器出错用 `--regrade` 对原产物离线重评，不重跑模型。

## 怎么跑

```bash
./gradlew :agent:cli:installDist
# 模拟模型调通（不花真钱）：
py -3 mock_model.py 18099 &
EVAL_MOCK_URL=http://127.0.0.1:18099 EVAL_MOCK_KEY=mock-key py -3 evaluate.py \
  --cli-home agent/cli/build/install/cli --evidence <目录> \
  --provider mock --model scripted --base-url http://127.0.0.1:18099 --wire anthropic \
  --key-env EVAL_MOCK_KEY
# 判分器变异验证：
py -3 check_grader_v1.py <模拟证据目录>
# 真模型完整一轮（key 只在同一条命令的环境变量里，不落盘）：
<KEY>="$(cat <keyfile>)" py -3 evaluate.py --cli-home … --evidence <目录> \
  --provider lunora --model gpt-5.6-luna --base-url https://api.uselunora.com/v1 \
  --wire openai_responses --key-env <KEY>
```

- 每题一个隔离的 `user.home`（`-Duser.home=<证据目录>/home/<题号>`）：会话、用户层配置、MCP 状态都
  不碰开发机真实档案。凭证只进本机 TraceProxy（live_smoke.py），子进程拿一次性 token，产物写盘前脱敏。
- 证据目录必须在仓库外；`--regrade <目录>` 用原产物离线重评。

## 钉进题目的 m0 现状（改行为时这些题会变红，属预期）

- **WebFetch 拒绝环回地址**（spi/WebUrl.kt：`localhost` / 无点主机名直接拒绝，http 强升 https）：
  43 题判「WebFetch 被拒 + 模型按提示改用 Bash curl 完成取页」。
- **Edit / NotebookEdit 的先读保护**：未先 Read 过的文件拒绝修改（「修改 …之前先用 Read 读一遍」）。
- **Read 工具直接读 Device 级路径不弹审批**（38 题实测；Bash 间接读才要求批准）——口径以实测为准，
  m0 行为变化时此题结果随之变化。
- **子 agent 的审批无人应答会挂到超时**（无头 `-p` 只自动应答根会话的审批）：32 题 fixture 用
  `permissionMode: acceptEdits` 的自定义 agent 绕开；这是 m0 的一个已知坑，不是题目要考的行为。
- 斜杠命令的位置参数 `$N` **从 0 起数**（`$0` 是第一个参数）；25/26 题按此出题。
